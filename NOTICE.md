# Credits

The table composition, vector artwork, family palette, prepared images, templates and build tools are original RectoVerso work, © Simon Pinkas, CC BY 4.0.

The factual element records (atomic numbers, symbols and English/French labels) derive from Wikidata structured data, CC0 1.0. Each record keeps its entity ID. The retrieval hash, spelling adjustments and verification sources are in `source/provenance.json`. No external table artwork or explanatory prose is included.

IUPAC's 4 May 2022 table verifies symbols, atomic numbers, group positions and periods. The Geneva education table, FranceTerme and CNRS UTINAM support selective French spelling checks. These references are consulted, not copied into the artwork or redistributed.

SF Pro is provided by macOS and is rasterized during the build. Its font file is not distributed. The PNG build records the loaded font family's identity and file digest. Anki and Qt remain separately licensed dependencies; their code is not vendored here.
